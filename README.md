Build rockets, travel to the Moon, Mars, Venus, and Mercury, and establish space colonies.

![Ad Astra — Space Exploration Mod Preview](https://cdn.modrinth.com/data/3ufwT9JF/images/608c0354187296edf5d6008282302cf44568068a_350.webp)

## Features

- Build and launch rockets to reach other planets
- Moon, Mars, Venus, Mercury, and Glacio biomes
- Space suits required to survive in vacuum
- Planet-specific ores and materials for progression
- Oxygen Distributor to make stations habitable

## Installation

1. Install [Minecraft Forge](https://files.minecraftforge.net/) for your version
2. Download the JAR for your Minecraft version above
3. Place the JAR into your `.minecraft/mods/` folder
4. Launch Minecraft with the Forge profile

## Requirements

- **Mod Loader:** Forge
- **Minecraft:** 1.16.5 / 1.18.2 / 1.19.2 / 1.20.1
